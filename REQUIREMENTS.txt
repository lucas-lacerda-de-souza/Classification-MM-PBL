🖥️ System Requirements
- Operating System
Ubuntu 20.04.1 LTS (64-bit)
Fully compatible with CUDA 12.8, PyTorch 2.8.0, multi-GPU training, and large-scale computational pathology workflows.

- Programming Language
Python 3.12.11

- Core Deep Learning Frameworks
PyTorch 2.8.0 (CUDA 12.8)
TorchVision 0.19.0
TorchAudio 2.8.0

These libraries support:
Multi-GPU training (DataParallel)
Mixed-precision computation
CNN- and transformer-based architectures
Large-batch inference and Grad-CAM computation

- Data Handling and Scientific Computing
NumPy 1.26.4
Pandas 2.2.3
Scikit-learn 1.5.2
OpenPyXL 3.1.5 (for structured clinical metadata in Excel format)

- Visualization
Matplotlib 3.9.2
Seaborn 0.13.2

Used for:
ROC curves
Calibration plots
Confusion matrices
Morphometric data visualization

- Image Processing
Pillow 10.4.0
- Used for:
Patch loading
Image resizing
RGB preprocessing of H&E images

- Utilities
tqdm 4.66.5
Provides progress bars for training, inference, and Grad-CAM generation.

- Model Interpretation and Explainability
SHAP - Used for feature attribution in XGBoost and multimodal models.
Grad-CAM - Implemented directly within this repository for CNN and CellViT explainability.

- Conda Environment and Channels
The project was developed using conda, with the following channels:
pytorch
nvidia
defaults
These channels ensure access to CUDA-enabled builds compatible with PyTorch 2.8.0 and multi-GPU execution.

- Data and Code Availability
- Data
Whole-slide images and clinical data cannot be publicly released due to ethical restrictions.
Synthetic demo data and example patches are provided for testing and inference.

- Code
Full implementation available at: https://github.com/lucas-lacerda-de-souza/Classification-MM-PBL

- Model Weights
Trained models, segmentation weights, and multimodal checkpoints are publicly available via Zenodo (https://doi.org/10.5281/zenodo.17988749).
